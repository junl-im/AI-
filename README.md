# AI Shorts Studio v1.6.12

로컬 영상 분석·쇼츠 편집·렌더링 도구이며 오디오·모션·추천·렌더를 분리한 모듈형 엔진을 사용합니다. 이번 릴리스는 브라우저 비전 모델 팩의 CPU/GPU 성능 진단과 안전 롤백을 추가합니다.

## 주요 변경

- 설치된 MediaPipe 얼굴 감지 모델을 GPU와 WASM CPU에서 로컬 측정
- 중앙 처리 시간, p95 지연, 추정 FPS 기록
- 장치별 권장 실행 경로 자동 선택
- 새 모델 활성화 실패 시 이전 검증 모델로 자동 복구
- 사용자가 이전 모델로 수동 복구하고 다시 되돌릴 수 있는 양방향 롤백
- 벤치마크·복구 이력은 브라우저 로컬 저장소에만 보존

## 실행

정적 파일 서버에서 `index.html`을 엽니다. 모델 팩은 공식 MediaPipe Tasks Vision 런타임과 얼굴 감지 모델 파일을 사용자가 직접 선택해 설치합니다.
