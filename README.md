# AI Shorts Studio v1.6.30

브라우저 안에서 원본 미디어를 분석하고 세로 쇼츠 후보를 편집·렌더링하는 로컬 우선 정적 웹 스튜디오입니다. 분석·미리보기·렌더·저장 책임을 나눈 **모듈형 엔진** 구조를 유지합니다.

## v1.6.30 화자 Grid Paging 고도화

- 실제 오디오 분석의 `rmsNorm`을 cue별 발화 에너지로 집계
- 에너지가 높은 활성 화자를 대기 시간 없이 상위 grid에 즉시 배치
- 주 화자는 에너지 paging 중에도 고정
- 사용자 지정 subject ID 순서로 최대 12개 수동 페이지 구성
- 페이지 전환 `없음`·`fade`·`slide` 지원
- 전환 시간 120~1200ms 설정
- 선택한 화자 cue 전체에 현재 grid crop X/Y/확대를 일괄 적용
- 미리보기와 최종 캔버스 렌더러가 동일한 페이지·전환 진행률 사용
- 기존 1인·2인 dual·3~4인 grid·시간 순환·우선순위 고정 정책 유지

## 핵심 동작

### 발화 에너지 즉시 전환

전사 cue 시간 범위에 포함되는 오디오 분석 프레임의 `rmsNorm` 평균을 0~1 범위의 cue 에너지로 저장합니다. `energy` 정책은 명시적인 주 화자를 고정한 채 나머지 자리를 현재 활성 cue의 에너지 순으로 즉시 갱신합니다.

### 수동 페이지

페이지는 쉼표로 구분한 subject ID 목록이며 `|`로 페이지를 나눕니다. 페이지당 최대 4명, 최대 12개 페이지로 제한하고 현재 활성 화자와 일치하지 않는 ID는 안전하게 제외합니다. 유효한 수동 페이지가 없으면 기존 시간 순환 정책으로 복귀합니다.

### 페이지 전환

`fade`와 `slide`는 이전 페이지·현재 페이지·전환 진행률을 엔진 focus에 포함합니다. 렌더러는 별도 RAF나 timer를 만들지 않고 기존 preview/render 프레임 시간으로 전환을 계산합니다. 에너지 즉시 전환과 우선순위 고정 정책은 지연 없이 현재 페이지를 사용합니다.
