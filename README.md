# AI Shorts Studio v1.6.32

브라우저 안에서 원본 미디어를 분석하고 세로 쇼츠 후보를 편집·렌더링하는 로컬 우선 정적 웹 스튜디오입니다. 분석·미리보기·렌더·저장 책임을 나눈 **모듈형 엔진** 구조를 유지합니다.

## 페이지별 화자 표시 시간

- 수동 페이지마다 1~10초의 독립적인 표시 시간을 설정합니다.
- 페이지 선택은 각 페이지 시간의 누적 합으로 계산하며 전체 주기가 끝나면 첫 페이지로 순환합니다.
- 페이지를 위·아래로 재정렬하면 표시 시간도 같은 페이지와 함께 이동합니다.
- 유효하지 않거나 누락된 값은 기존 전역 페이지 시간으로 안전하게 복구합니다.

## 페이지 내부 화자 순서 편집

- 페이지 안의 화자를 drag-and-drop으로 재정렬합니다.
- 좌·우 이동 버튼을 키보드 접근 가능한 대체 경로로 제공합니다.
- 최대 12개 페이지·페이지당 최대 4명 제한을 유지합니다.
- 변경된 순서는 미리보기, 엔진 focus, 프로젝트 저장과 undo/redo에 함께 반영됩니다.

## 실시간 에너지·Hold 상태

- 현재 활성 화자별 에너지를 막대로 표시합니다.
- 현재 grid에 선택된 화자를 시각적으로 구분합니다.
- energy threshold와 신규 화자 hold 남은 시간을 재생 프레임 기준으로 표시합니다.
- 별도의 RAF·interval을 추가하지 않고 기존 preview 렌더 동기화 경로를 사용합니다.

## 실행

정적 파일 서버에서 프로젝트 루트를 열고 `index.html`에 접속합니다. 미디어·모델·진단 정보는 로컬 우선으로 처리됩니다.
