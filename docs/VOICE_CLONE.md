# VOICE CLONE EXECUTION

## 목표

SoriON의 목소리 복제는 모바일에서 다음 흐름으로 끝난다.

```text
녹음 또는 파일 선택
→ 품질 확인과 명시적 동의
→ 음성 프로필 준비
→ 문장별 실제 복제 실행
→ Dock에서 즉시 재생
```

## 로컬 우선

- 브라우저는 길이, 무음 비율, 클리핑, 음량을 기기에서 먼저 계산한다.
- 준비된 프로필과 원본 Blob은 IndexedDB `voiceProfiles`에 저장한다.
- API가 연결되지 않아도 로컬 프로필을 만들 수 있다.
- 사용자가 동의를 철회하면 IndexedDB와 API 임시 저장소의 샘플 삭제를 요청한다.
- Firebase 또는 다른 클라우드로 자동 업로드하지 않는다.

## 명시적 동의

복제 준비 전에 다음 세 항목을 모두 확인한다.

1. 본인 목소리이거나 명시적인 사용 권한을 받았다.
2. 필요한 경우 AI 합성 음성임을 이용자에게 알린다.
3. 사칭, 사기, 기만, 동의 없는 복제에 사용하지 않는다.

동의 기록에는 시각과 사용 목적을 저장한다. 체크되지 않은 요청은 API에서
`SOA-5001`로 차단한다.

## 품질 기준

- 5초 미만: 차단
- 10초 미만: 재녹음 권장
- 10초: 기본 권장 길이
- 30초: 안정적인 특징 확보를 위한 권장 길이
- 클리핑 비율 2% 초과: 차단
- 무음 비율 58% 초과: 경고
- RMS -38dB 미만: 작은 음량 경고

브라우저 분석은 사용 편의를 위한 1차 검사다. WAV는 API에서 컨테이너와 최소 길이를
다시 검사한다. MP3, M4A, WEBM, OGG의 서버 파형 재분석은 다음 배포 단계에서 추가한다.

## CosyVoice Worker 경계

- FastAPI 게이트웨이는 torch와 대형 모델을 직접 import하지 않는다.
- `SORION_COSYVOICE_WORKER_URL`이 설정된 경우 Worker `/health`와 `/ready`를 확인한다.
- Worker는 GPU, CUDA, VRAM, 모델 경로, adapter 상태를 진단한다.
- 실제 adapter 또는 모델이 없으면 작업 생성은 HTTP 503이다.
- 실제 복제 성공으로 표시하지 않는다.

## 실제 실행

동의된 프로필에서 최대 500자 문장을 입력하면 FastAPI가 원본 샘플과 문장을 Worker에
전달한다. Worker는 문장을 구간으로 나눠 독립적으로 생성한다.

- 전체·구간별 진행률
- 첫 구간 음성 지연 시간
- 작업 취소
- 실패·취소 구간만 재시도
- 구간 WAV 조회
- 최종 PCM WAV 병합
- 완료 결과 Dock 자동 연결

SSE 이벤트 경로를 제공하지만 현재 Web UI는 네트워크 복구가 단순한 750ms 상태 조회를
사용한다. 다음 버전에서 마지막 이벤트 ID 기반 자동 재연결로 전환한다.

## 원본 보관

API 임시 저장소 기본값:

```text
.sorion/voice-clones
```

- 파일명은 사용자 파일명이 아닌 UUID를 사용한다.
- 최대 파일 크기는 기본 25MB다.
- 기본 보관 기한은 7일이다.
- 원본 파일을 공개 다운로드 라우트로 제공하지 않는다.
- 메타데이터에는 동의와 품질 정보만 저장하고 비밀 토큰은 저장하지 않는다.

## 모델 포함 정책

일반 릴리스 ZIP에는 모델 가중치, torch, torchaudio, CosyVoice 저장소를 포함하지 않는다.
실제 배포 서버에서 별도 설치하고 Worker readiness가 성공한 경우에만 생성 버튼을 연다.
