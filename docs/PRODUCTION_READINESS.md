# Korean TTS Production Readiness

## 목적

`0.5.0`은 대형 모델을 프로젝트에 포함하는 버전이 아니다. 사용자가 로컬 또는 별도 서버의 FastAPI를 모바일 웹과 연결하고, 실제 생성 상태를 이해하며, 품질 평가를 다음 작업까지 보존할 수 있게 하는 운영 연결 버전이다.

## 3단계 연결

1. 설정 화면에서 `http://127.0.0.1:8000` 또는 운영 API 주소를 입력한다.
2. `연결 검사`를 눌러 Python, 임시 음원 폴더, 실제 한국어 엔진, CORS 상태를 확인한다.
3. `주소 저장`을 누르면 이 기기의 `localStorage`에 `/api/v1` 주소가 저장된다.

주소 변경 이벤트가 발생하면 엔진 목록을 다시 읽는다. 비밀키나 인증 토큰은 이 설정에 저장하지 않는다.

## 작업 진행률

`POST /api/v1/tts/synthesize`는 최종 결과가 나올 때까지 유지된다. 웹은 같은 `job_id`로 `GET /api/v1/tts/jobs/{job_id}`를 주기적으로 조회한다.

진행 단계:

- `queued`
- `normalizing`
- `generating`
- `merging`
- `completed`
- `cancelled`
- `failed`

긴 문장은 현재 구간과 전체 구간 수를 함께 표시한다. 완료·실패·취소 상태는 최근 작업 스냅샷에 남아 결과 응답 이후에도 조회할 수 있다.

## 품질 평가 보존

별점과 메모는 브라우저 IndexedDB의 `qualityReviews` 저장소에 보관한다. 평가 문장과 엔진 ID 조합별로 최신 평가를 갱신한다.

내보내기 형식:

- JSON: 앱 버전, 내보낸 시각, 전체 평가 객체
- CSV: UTF-8 BOM, 한국어 열 제목, 생성 시간·음원 길이·RTF 포함

평가 문장에는 개인 정보가 포함될 수 있으므로 파일 공유 전 내용을 확인한다.

## 현재 한계

- 모델 설치 자체를 자동화하지 않는다.
- MeloTTS 모델은 API 프로세스 안에서 지연 로딩된다.
- 구간별 실패 재시도와 worker 프로세스 분리는 후속 서버 운영 버전에서 진행한다.
- MP3·FLAC 변환은 아직 활성화하지 않으며 FFmpeg는 선택 진단만 한다.
