# Natural Playback Control Flow

SoriON AI 0.9.7의 재생 버튼은 실제 음원 이벤트보다 사용자 입력에 먼저 반응합니다.

## 사용자 순서

1. 준비된 음성에서 `재생`을 누릅니다.
2. 버튼이 즉시 `일시정지`로 바뀝니다.
3. 음원 또는 Browser Speech가 실제 시작되면 같은 상태를 유지합니다.
4. `일시정지`를 누르면 준비 중이거나 재생 중인 요청을 멈추고 `재생`으로 돌아갑니다.
5. 음원이 끝나거나 오류가 발생해도 `재생` 상태로 복원됩니다.

## 경합 보호

- 파일 음원은 `play()` Promise가 완료되기 전에 UI를 먼저 전환합니다.
- 준비 중 다시 누르면 `pause()`를 호출하고 optimistic 상태를 취소합니다.
- Browser Speech는 실행별 run ID를 사용합니다.
- 취소된 utterance의 늦은 `onstart`, `onend`, `onerror`는 무시합니다.

## 접근성

- 현재 버튼 이름은 `재생`, `일시정지`, `다음 구간 대기` 중 하나입니다.
- `aria-pressed`가 현재 재생 의도를 전달합니다.
- 재생 중 버튼은 색상과 그림자가 함께 바뀌며 색상만으로 상태를 구분하지 않습니다.
