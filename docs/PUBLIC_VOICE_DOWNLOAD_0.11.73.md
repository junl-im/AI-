# 0.11.73 공개 사이트 기본 성우 다운로드 검증

2026-10-23 KST, Windows PC 한 대에서 공개 Pages 0.11.72와 0.11.71 Windows 보조 앱을 사용했습니다. 보조 앱이 연 토큰 포함 주소로 새 브라우저 프로필에 접속했고, 화면에서 `장문 음성 스튜디오 시작` → 대사 입력 → `생성 및 재생` → `Windows 보조 앱으로 원래 음색 MP3 저장`을 실제로 눌렀습니다. 시험 대사는 `안녕하세요. 소리온 공개 사이트 기본 성우 저장 검사입니다.`이며 두 대사 클립으로 분할됐습니다. `기본 성우 WAV 다운로드` 링크도 실제로 눌렀습니다.

| 환경 | MP3 결과 | 재디코딩 결과 | WAV 결과 |
| --- | --- | --- | --- |
| Chrome, 이 PC | 112,013바이트, MPEG 프레임 `fffb90c4` | 7.001초, 피크 0.565 | 614,000바이트, `RIFF` |
| Edge, 이 PC | 110,759바이트, MPEG 프레임 `fffb90c4` | 6.922초, 피크 0.565 | 링크는 표시됐으나 이 Edge 시험에서 직접 내려받지 않음 |

Chrome에서 `Windows 보조 앱으로 원래 음색 MP3 저장` 버튼이 활성화됐고, Edge에서도 같은 공개 사이트 버튼으로 실제 MP3 파일을 받았습니다. 두 결과 모두 무음 파일이 아님을 디코딩과 신호 피크로 확인했습니다. 시험 중 표시된 기본 프리셋은 혜린이었고, Chrome의 한국어 음성 목록은 Microsoft Heami와 Google 한국의, Edge는 Heami·선히·인준·Hyunsu였습니다. 생성된 파일의 청감과 프리셋별 음색 일치는 사람이 청취해 확인하지 않았습니다.

두 브라우저는 **같은 Windows PC·출력 장치·보조 앱**을 사용했습니다. 다른 사람의 PC, 실제 일반 창에서의 로컬 네트워크 권한 프롬프트, 남성 성우 각각의 음색, 다중 긴 대사·취소 복구는 검증하지 않았습니다. 헤드리스 브라우저에는 `loopbackNetwork` 권한을 자동 부여했습니다. 공개 사이트의 UI 클릭 동선은 검증했지만 다른 PC에서의 동작을 보증하지 않습니다.
