# 0.11.70 · MP3 직접 다운로드 실측

2026-10-23 KST, 로컬 Vite에서 제품의 `GeneratedAudioSave`, `synthesizeSupertonicWav`, `buildTimelineWav`, `wavToMp3`를 사용했습니다. 기기 성우가 실패한 상태의 한국어 대사 `안녕하세요. 소리온 MP3 다운로드 검사입니다.`에서 `파일 음성으로 생성해 MP3 저장`을 한 번 클릭했습니다.

- Chrome headless의 실제 다운로드 폴더에 `sorion-full.mp3` 74,814바이트가 생성됐고 MPEG 프레임 헤더 `FF FB 90 C4`를 확인했습니다. WAV 버튼을 추가로 클릭하지 않았으며 다운로드 폴더에는 MP3만 있었습니다.
- Edge 155 (`msedge.exe`)는 별도 프로필과 디버깅 포트로 시작했으나 헤드리스 프로세스가 종료 코드 0으로 곧바로 끝나 시험 페이지에 진입하지 못했습니다. Edge의 MP3 직접 저장 결과는 **미검증**입니다.
- 0.11.69 응답에서 Edge 실측을 통과했다고 보고한 것은 시험 스크립트의 브라우저 실행 경로가 Chrome에 고정돼 있어 잘못된 결론이었습니다. 이 기록으로 바로잡습니다.

이 검사는 이 PC의 로컬 Vite와 저장 컴포넌트에서 실제 모델 합성부터 다운로드까지 확인한 결과입니다. 공개 Pages 전체 대본 입력 흐름, 사용자의 다른 PC, 기본 성우 원본 음색과의 일치 및 청취 품질은 검증하지 않았습니다. 임시 시험 페이지·브라우저 프로필·다운로드 폴더는 제거했습니다.
