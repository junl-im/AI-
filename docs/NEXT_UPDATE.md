# NEXT UPDATE

## 목표 버전

`0.6.0 CosyVoice 3 & Mobile Voice Clone Foundation`

## 제품 방향

SoriON AI는 한국인이 모바일에서 앱처럼 사용하며 10초 안에 음성 생성·복제·변환을 시작하는 차세대 AI Voice Platform이다. 연구 도구처럼 엔진 설정을 앞세우지 않고, 기본값만으로 좋은 한국어 음성을 만들며 전문가는 Advanced에서 엔진과 세부 설정을 선택한다.

## 엔진 결정

- 주력 TTS·제로샷 복제: Fun-CosyVoice 3
- 복제 전문가용 보조: GPT-SoVITS
- 로컬 대체: MeloTTS, 운영체제 음성
- 평가 전용: Fish Audio S2

선정 근거와 라이선스 주의사항은 `docs/ENGINE_STRATEGY.md`에 기록한다.

## 예상 구현

- 별도 Python worker 프로세스 기반 `CosyVoiceEngine` 어댑터
- 모델 설치, 다운로드, GPU·메모리 사전 진단
- 스트리밍 TTS API와 첫 음성 지연 측정
- 모바일에서 10초 참조 음성 녹음·파일 업로드
- 녹음 길이, 무음, 클리핑, 소음 사전 검사
- 본인 음성 또는 정당한 권한 확인과 명시적 동의
- 제로샷 목소리 복제 요청 계약
- 생성 취소, 타임아웃, 진행률, 실패 구간 재시도
- 실제 AI, 로컬 대체, Demo 결과의 명확한 구분
- 한국어 숫자·날짜·영문 혼용 발음 평가

## 성능 목표

- 요청 접수 표시 100ms 이내
- 스트리밍 첫 음성 목표 1초 이내
- 짧은 문장 전체 생성 목표 10초 이내
- 생성 취소 반영 500ms 이내
- 모바일 핵심 흐름은 주요 조작 3회 이내

## 절대 조건

- 타인의 목소리를 동의 없이 복제할 수 없게 한다.
- 음성 원본은 기본 로컬 보관이며 자동 클라우드 업로드를 금지한다.
- 실제 모델이 준비되지 않았으면 성공한 AI 음성처럼 표시하지 않는다.
- 상업 사용 제한 엔진은 기본 엔진으로 자동 활성화하지 않는다.
- 엔진은 Adapter 뒤에 두어 한 모델에 종속되지 않는다.
