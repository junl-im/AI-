# Chat-to-Timeline Workspace

버전: `0.8.4`

## 제품 구조

SoriON의 생성 경험은 두 층으로 나뉜다.

- 바깥층: ChatGPT형 대화와 자연어 요청.
- 안쪽층: CapCut형 음성·쉼 타임라인.

초보자는 대화만 입력하고 전문가는 생성 결과 블록을 편집한다.

## 화면 전환

1. 첫 로드에는 브랜드 랜딩을 표시한다.
2. 시작 버튼이나 저장 프로젝트를 누르면 `workspaceEntered=true`가 된다.
3. 대형 Masthead는 compact header로 교체된다.
4. PC는 보이스 라이브러리·대화·타임라인을 동시에 표시한다.
5. 모바일은 선택된 보이스 요약만 먼저 보이고, 펼치면 세로 보이스 목록이 나타난다.
6. 작업공간의 불필요한 외곽 카드·중간 테두리는 제거하고 편집 영역을 full-bleed로 사용한다.

## 메시지 처리

- 직접 문장: 그대로 TTS 대상.
- 대본 요청: 실제 LLM이 없으므로 로컬 3문장 초안 생성.
- 로컬 초안은 `LLM 미연결` 배지를 반드시 표시한다.
- 추천 칩은 발화 텍스트에 섞지 않고 TTS 옵션으로 변환한다.

## Progressive 생성

문장을 분할한 뒤 순차적으로 API에 요청한다. 각 문장이 완료되는 즉시:

1. 타임라인 블록을 ready로 변경한다.
2. GeneratedAudio를 Player Store에 enqueue한다.
3. Dock 플레이어가 나타난다.
4. 다음 문장 생성을 계속한다.

API 미연결 상태에서는 블록을 queued로 유지하고 시스템 자동 탐색을 요청한다.

## 연결 상태

- API: FastAPI `/health`와 통합 Connectivity 상태.
- TTS: 실제 엔진 준비, Demo 전용, 미준비를 서로 구분한다.
- Worker: `clone-worker-health` 검사.
- GPU: CosyVoice model readiness.

브라우저는 임의의 LAN 전체 대역을 스캔하지 않는다. 같은 Origin, 배포 환경변수,
성공 이력과 현재 HTTP 호스트의 안전 후보만 자동 검사한다.

## 편집 계약

- 드래그 또는 좌우 버튼으로 순서 변경.
- 가위 버튼은 문장을 공백에 가까운 중간 지점에서 분할.
- 더블클릭 또는 550ms 길게 누르기로 텍스트 수정.
- 수정·분할 시 연결된 이전 track을 대기열에서 제거.
- 실패 블록은 개별 재시도. 재시도는 해당 블록에 저장된 보이스·감정·속도·엔진 옵션을 그대로 사용한다.
- 쉼 블록은 현재 0.5초 고정이며 다음 버전에서 길이 조절 예정.
