# UI GUIDE

## 모바일 기준

- 기본 검증 폭: 360px, 390px, 430px
- 터치 대상 최소 높이: 44px, 권장 52px
- 주요 행동은 한 화면에 하나만 강조
- 핵심 작업은 3번 이내 터치로 시작
- 하단 고정 내비게이션은 최대 4개 항목

## 시각 언어

- Apple의 정돈된 밀도
- Notion의 단순한 정보 구조
- ChatGPT의 대화형 친근함
- 넓은 여백, 둥근 카드, 강한 제목, 절제된 애니메이션

## 애니메이션

- 일반 전환 180~300ms
- `prefers-reduced-motion` 존중
- 애니메이션이 기능 완료를 지연시키지 않음

## 한국어

- 버튼은 동사로 작성: `음성 생성 시작`
- 기술 오류를 그대로 노출하지 않음
- 존댓말을 일관되게 사용
- 줄바꿈 시 조사와 단위를 가능한 한 분리하지 않음

## 아이콘

프로젝트 원칙에 따라 SVG 파일과 SVG 아이콘 라이브러리를 사용하지 않는다. PNG 또는 CSS·문자 기반 아이콘을 사용한다.
