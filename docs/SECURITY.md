# SECURITY

## 핵심 위협

- 타인의 목소리를 무단 복제하거나 사칭하는 행위
- 사용자 음성·문장의 무단 저장과 재사용
- API 키와 서비스 계정 유출
- 과도한 생성 요청과 비용 공격
- 악성 오디오 업로드

## 음성 복제 원칙

- 본인 또는 적법한 권리자의 명시적 동의가 필수
- 동의 확인 전 복제 엔진을 호출하지 않음
- 생성물에 출처와 합성 여부를 표시할 수 있어야 함
- 신고, 삭제, 차단 절차를 제품 기능으로 제공
- 공인·유명인 사칭 방지 정책을 별도로 운영

## 데이터

- 음성 원본과 원문을 애플리케이션 로그에 기록하지 않음
- 전송과 저장 구간 암호화
- 최소 보존 기간과 사용자 삭제 기능
- 개발·운영 Firebase 프로젝트 분리

## 비밀 관리

Firebase 웹 설정값은 환경 변수로 관리한다. 서비스 계정, AI 공급자 키, 결제 키는 서버 비밀 저장소에서만 사용하며 클라이언트 번들에 포함하지 않는다.

## 신고

보안 문제는 공개 이슈가 아닌 비공개 채널로 접수한다. 실제 운영 전 `security@` 연락처를 확정한다.
