# TEST

## 계층

1. 단위 테스트: 파일 검증, 텍스트 정규화, 엔진 옵션 변환
2. API 계약 테스트: 요청 검증과 공통 응답
3. 컴포넌트 테스트: 입력, 오류, 로딩, 접근성
4. E2E: 생성 시작, 프로젝트 저장, 로그인, PWA 업데이트
5. 실기기: Android Chrome, iOS Safari, 설치형 PWA

## 명령

```bash
npm run quality:rules
npm run test
npm run test:api
```

## 배포 차단 기준

- 테스트 실패
- 500줄 제한 위반
- 실제 동작하지 않는 주요 버튼
- 한국어 오류 메시지 누락
- 모바일 360px 가로 스크롤
- 사용자 음성 또는 비밀키 저장소 포함

## AI 품질 평가 예정

한국어 평가 세트에는 숫자, 날짜, 영문 혼용, 외래어, 조사, 경어, 감정 문장을 포함한다. 속도뿐 아니라 자연스러움, 발음, 화자 유사성, 잡음, 안정성을 별도 점수로 기록한다.
