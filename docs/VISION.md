# VISION

## 제품 정의

SoriON AI는 **한국어 장문 제작을 중심으로 한 모바일 우선 AI Voice Platform**이다.
한 문장 데모가 아니라 광고 대본, 오디오북, 강의, 더빙 원고를 붙여 넣고 문장별로 생성·편집·
복구하는 전체 제작 흐름을 제공한다.

## 약속

- 긴 한국어 원고를 빠르게 문장별 음성으로 만든다.
- 숫자·날짜·단위·영문 약어와 한국어 호흡을 자연스럽게 다듬는다.
- 초보자는 원고·목소리·제작 버튼에 집중하고 전문가는 타임라인을 정밀 편집한다.
- 엔진 연결·선택·fallback은 시스템이 처리하며 사용자에게 API 주소를 요구하지 않는다.
- 실제 AI, Local/System, Mock, Browser Demo를 숨기거나 혼동시키지 않는다.
- 목소리 복제는 명시적 권리 확인과 동의를 전제로 로컬 우선으로 운영한다.
- 모바일 종료와 네트워크 단절 뒤에도 원고와 job 결과를 복구한다.

## 차별점

- ChatGPT형 대화가 아니라 **장문 원고 작업에 맞는 제작 IA**
- CapCut형 문장·쉼 타임라인과 첫 블록부터 재생되는 Linked Player Dock
- 한국어 정규화와 교체 가능한 Engine Adapter
- SQLite job 영속화와 브라우저 세션 revision 보호
- API·TTS·Worker·GPU 계층을 분리한 정직한 준비 상태
