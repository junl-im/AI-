# Always-on Preset Runtime & PC Three-Pane Layout

SoriON AI 0.10.0은 사용자가 엔진 연결 상태를 관리하지 않아도 프리셋 음성과 작업 화면이 자연스럽게 이어지는 것을 목표로 한다.

## Always-on Preset Runtime

- 프리셋 미리듣기 요청은 현재 엔진이 준비되지 않았더라도 내부 대기열에 유지한다.
- API·Worker 또는 브라우저 음성이 준비되면 같은 프리셋 요청을 자동으로 다시 실행한다.
- 실패한 미리듣기는 1초부터 최대 15초까지 점진적으로 재시도한다.
- 새 프리셋을 선택하면 이전 대기 요청과 늦게 도착한 결과를 무효화한다.
- 일반 작업 화면에는 API, Worker, GPU, 엔진 주소를 표시하지 않는 연결 상태 비노출 원칙을 적용한다.
- 연결 복구는 12초 활성 heartbeat, 45초 백그라운드 heartbeat, 60초 전체 점검으로 유지한다.
- 창 포커스, 페이지 복귀, 네트워크 변경, 온라인 복귀 시 자동 재연결을 즉시 요청한다.

## PC 3분할

1024px 이상의 PC 작업 화면은 다음 세 영역을 동시에 표시한다.

1. 왼쪽 프로젝트 목록
2. 중앙 대본·대화·타임라인 작업공간
3. 오른쪽 프리셋 음성 및 세부 설정

기존 1180px 기준은 1024px로 낮췄다. 이전 접힘 상태가 계속 남아 3분할이 보이지 않는 문제를 피하기 위해 레이아웃 저장 키를 `sorion.desktop-studio-layout.v2`로 갱신하고, 좌우 패널은 기본 확장 상태로 시작한다.

## 사용자 화면 원칙

- 사용자는 연결 버튼이나 서버 주소를 입력하지 않는다.
- 연결이 끊기면 내부에서 자동 재연결한다.
- 일반 화면은 결과와 작업 흐름만 보여주며 연결 상태는 보여주지 않는다.
- 상세 기술 진단은 설정의 고급 진단 영역에서만 확인한다.
