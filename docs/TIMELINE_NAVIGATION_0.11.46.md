# 0.11.46 타임라인 탐색과 대본 복귀

타임라인 클립의 시각적 폭은 편집용 추정 길이입니다. 클릭 위치를 실제 재생 위치로 옮길 때는 큐에 연결된 음원의 실제 길이를 사용합니다. 부분 음원과 브라우저 음성은 임의 위치 탐색을 지원하지 않으므로 요청하지 않습니다.

연계 플레이어 위치 버튼은 마우스 클릭과 함께 화살표 좌우 5초, Home/End 처음·끝 이동을 지원합니다. 프로젝트 저장소 읽기에 실패해도 `대본 계속 편집`은 작업공간을 초기화하지 않고 편집 화면으로 돌아갑니다. 저장소 오류 자체는 재시도 또는 브라우저 저장 권한 확인이 필요합니다.

검증: 관련 Web 회귀 31개, Web 전체 333개, API 244개 통과/1개 건너뜀, Worker 16개, lint/typecheck/build/Ruff·preflight 55/55 통과. CI·배포 결과는 릴리스 결과에서 확인합니다. 실제 승인 성우 WAV/모델이 없어 장문 청취·Neural 품질을 인증하지 않습니다.
