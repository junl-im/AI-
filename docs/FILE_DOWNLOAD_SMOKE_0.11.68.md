# 0.11.68 · 파일 다운로드 실측

2026-10-23 KST, 로컬 Vite 서버와 Chrome headless의 실제 저장 경로를 사용했습니다. 저장 화면과 동일한 `GeneratedAudioSave` 컴포넌트에 브라우저 음성 대사 한 개를 넣고, `파일 음성으로 생성해 WAV 저장` 버튼을 클릭했습니다. 제품의 `synthesizeSupertonicWav`, `buildTimelineWav`, `wavToMp3`를 사용했습니다.

- 한국어 시험 문장: `안녕하세요. 소리온 파일 다운로드 검사입니다.`
- Chrome의 다운로드 디렉터리에 `sorion-full.wav` 369,964바이트 생성, RIFF 헤더 확인.
- 이어서 저장 화면의 `전체 MP3 다운로드` 버튼을 클릭해 `sorion-full.mp3` 67,709바이트 생성, MPEG 프레임 헤더 `FF FB 90 C4` 확인.
- 모듈 직접 호출 시험에서도 WAV 337,128바이트, 쉼 0.5초가 합쳐진 전체 WAV 381,228바이트, MP3 69,799바이트를 확인했습니다.
- 테스트용 페이지와 브라우저 프로필은 삭제했습니다. 테스트 파일은 릴리스에 포함하지 않습니다.

이는 이 PC의 Chrome에서 모델 생성→WAV 결합→브라우저 다운로드가 실제로 작동했다는 증거입니다. 사용자의 다른 PC, Edge, 다른 프리셋의 청취 품질, 기존 기기 성우와의 음색 일치는 검증하지 않았습니다. 첫 실행 모델 다운로드는 약 380MB이며 기기 메모리와 네트워크에 따라 실패할 수 있습니다.
