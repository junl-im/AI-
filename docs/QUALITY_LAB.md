# KOREAN VOICE QUALITY LAB

## 목적

`0.5.0` 품질 연구소는 한국어 TTS 엔진을 감으로만 선택하지 않고 동일한 문장과 설정으로 비교하기 위한 개발 도구입니다.

## 제공 기능

- Python 버전, 운영체제, 프로세스 메모리 표시
- MeloTTS 패키지 탐지와 모델 지연 로딩 상태
- Windows·macOS·Linux 시스템 음성 실행 파일 탐지
- 숫자·날짜·금액·퍼센트·영문 약어 전처리 미리보기
- 긴 문장 자동 분할 구간 확인
- 최대 두 엔진 A/B 생성
- 생성 시간, 음원 길이, RTF, 파일 크기, 구간 수 표시
- 브라우저 세션 안에서 별점과 청취 메모 작성

## RTF 해석

`RTF = 생성 시간 ÷ 음원 길이`입니다.

- `RTF < 1`: 음원 재생 시간보다 빠르게 생성
- `RTF = 1`: 실시간과 비슷한 속도
- `RTF > 1`: 음원 재생 시간보다 생성이 느림

RTF는 품질 점수가 아닙니다. 자연스러움과 발음 평가는 반드시 직접 청취해야 합니다.

## 한국어 전처리 범위

현재 초안은 다음 표현을 다룹니다.

- `2026-08-03` → `이천이십육년 팔월 삼일`
- `09:30` → `구시 삼십분`
- `38,500원` → `삼만 팔천오백 원`
- `95%` → `구십오 퍼센트`
- `AI` → `에이 아이`
- `1.5kg` → `일 점 오 킬로그램`

주소, 전화번호, 주민번호, 수식, 고유명사의 읽기 규칙은 아직 일반화하지 않습니다.

## WAV 병합 조건

장문 병합은 같은 엔진에서 생성한 비압축 PCM WAV를 대상으로 합니다. 채널 수, 샘플 폭, 샘플레이트가 다르면 병합을 중단합니다. 구간 사이에는 기본 120ms 무음을 넣습니다.

## 개인정보

별점과 메모는 현재 브라우저 메모리에서만 유지하며 API로 전송하지 않습니다. 생성 WAV는 API 임시 폴더에 저장되고 기본 30분 뒤 삭제됩니다.

## 알려진 제한

- 품질 보고서는 아직 영구 저장되지 않습니다.
- GitHub Pages만 실행하면 진단과 A/B 생성 API를 사용할 수 없습니다.
- MeloTTS 설치 성공 여부와 실제 모델 다운로드 용량은 환경마다 다릅니다.
- 엔진별 샘플레이트가 다를 경우 서로 다른 결과 파일은 비교할 수 있지만 하나로 병합하지 않습니다.

## Heartbeat 6.7 Evidence Intake와 로컬 ZIP

Quality Lab은 SoriON evidence v2와 완료된 Heartbeat 6.6·6.7 Web quality run report를 파일로 선택해 preview한 뒤 등록한다. checksum이나 schema가 틀리거나 동일 bundle·record가 이미 있으면 등록 버튼을 비활성화한다. Web quality report의 source commit SHA와 run ID는 파일에서 자동 채운다.

Local Export Bundle 카드는 WAV·MP3·SRT·VTT·JSON 최대 20개, 250MiB 이하를 서버 전송 없이 ZIP으로 만든다. 파일별 SHA-256 manifest, 진행률, 취소와 100MiB 초과 모바일 메모리 경고를 제공한다.
