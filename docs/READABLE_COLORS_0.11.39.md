# 0.11.39 · Readable Colors

## 원인과 수정
밝은 스튜디오 전환 후 어두운 테마의 하위 규칙이 남아 설정창의 어두운 카드 위에 어두운 글씨, 보조 페이지·타임라인의 밝은 바탕 위에 흰 글씨가 겹쳤습니다. 일부 라벨은 형광 강조색이나 낮은 불투명도를 유지했습니다.

readable-colors.css를 테마 마지막에 적용해 배경과 글자 쌍을 함께 맞췄습니다. 배경은 따뜻한 회색 #efeeeb, 주요 카드 #faf9f6, 입력 #f3f2ef로 정리했습니다. 본문 #30343b, 보조 #59616b, 강조 #655079를 사용합니다. 기존 dark track은 밝은 상태 글자를 유지해 어두운 트랙과 밝은 편집 도구의 대비를 구분했습니다.

- 스튜디오 placeholder·저장 상태·글자 수·대본 안내·선택 대상 안내를 진하게 조정.
- 음성 설정창의 검은 카드·파란 버튼을 밝은 카드·보라색 선택 상태로 통일.
- 품질/프로젝트/내 목소리/설정 제목과 설명의 흰 글씨 제거.
- 프로 패널의 흰 메뉴·미리듣기 아이콘과 형광 속도/말투 강조 보정.
- 타임라인의 희미한 흰색 도구·선택 편집·상태·시간 표시 보정.
- 내 목소리 녹음 단계 제목·라벨, 품질의 선택 설명 대비 개선.

## 검증
390/1440px Chrome에서 총 17개 화면을 검사했습니다. 보이는 활성 텍스트 노드의 계산된 전경과 조상 단색 배경을 합성해 일반 글자 4.5:1, 큰 글자 3:1 기준 미달 0건을 확인했습니다. 측정 글자 수와 화면별 결과는 docs/validation/0.11.39-contrast.json에 기록했습니다. 수정 전에는 음성 설정 라벨 약1.12:1, 보조 페이지 제목 약1.08:1, 타임라인 일부 글자 약1.02:1이었습니다.

단색 배경 계산은 그라데이션·이미지·모든 상호작용 상태·placeholder·비텍스트 컨트롤의 전체 접근성 인증을 대신하지 않습니다. 스크린샷으로 설정창과 프로 패널을 별도 육안 확인했고 실제 장치의 눈 피로도를 측정한 것은 아닙니다.
