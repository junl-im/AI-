# Mobile Studio Flow & Natural Voice Playback

버전: **0.11.11**

## 목표

모바일 첫 화면에서 플레이어·주요 네비게이션·목소리 선택·대본 입력·가로 타임라인이 서로 다른 조작 규칙을 갖지 않도록 하나의 작업 흐름으로 정리합니다. 자연스러움은 음질을 과장해 보장하지 않고, 프리셋별 권장 상황과 안전한 운율 범위를 UI에서 명확히 안내합니다.

## 변경 사항

- 홈 Dubbing Player 아래에도 주요 Dock을 노출해 화면별 네비게이션 차이를 제거합니다.
- 현재 목소리 1개만 One-Flow에 보이고 전체 목소리는 `목소리 선택` Sheet에서 비교합니다.
- 각 목소리는 잘 맞는 상황, 장점, 주의점과 재생 버튼을 제공합니다. 미리듣기는 선택 상태를 변경하지 않습니다.
- 대본 내용에 따른 추천은 보수적인 키워드/길이 휴리스틱이며 자동 적용하지 않습니다.
- 프리셋별 natural speed/pitch 범위를 정의하고 목소리 전환 시 현재 설정을 해당 범위로 보정합니다.
- 모바일 입력 focus와 visual viewport 변화 때 textarea를 상단 작업 위치로 재정렬합니다.
- 모바일 타임라인도 ruler/clip/playhead가 같은 X축을 사용하며 가로 스크롤과 1.25배 기본 zoom으로 화면 폭을 적극 사용합니다.
- player store의 명시적 재생 요청은 UI 상태를 즉시 연결하고 native play 실패 시 안전하게 원복합니다.

## 안전 경계

- `대본 맞춤 추천`은 음질·자연스러움 보장이 아니며 최종 목소리는 사용자가 선택합니다.
- 실제 CosyVoice 전용 프리셋의 자연스러움/품질은 승인된 WAV, 동의, 사람 검수 및 실기기 청취 증거가 준비된 뒤 평가합니다.
- 모바일 focus 정렬은 760px 이하에서만 동작하며 데스크톱 scroll 위치를 강제로 바꾸지 않습니다.
- 모바일 타임라인의 시간 좌표는 PC와 동일 geometry를 공유하며 화면에 맞추기 위해 시간 비율을 왜곡하지 않습니다.
