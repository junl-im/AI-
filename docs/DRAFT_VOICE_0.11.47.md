# 0.11.47 대본 저장 복구와 한국어 발화 정리

작업공간 저장이 메모리 전용이면 저장 상태 옆에 `저장 다시 시도`를 보입니다. 같은 현재 대본을 재저장하고, 저장이 성공하면 버튼이 사라집니다. 이 조치는 생성 완료 프로젝트 목록의 별도 저장을 재시도하지는 않습니다.

Web 타임라인과 API는 `첫 문장입니다.다음 문장입니다.`를 한국어 문장 경계로 인식합니다. 브라우저 음성도 문장부호 다음에 간격을 넣습니다. 숫자 `3.5`는 나누지 않습니다. 이 개선은 5개 기본 성우의 입력 리듬에 적용되지만 전용 Neural 성우의 음색이나 청취 자연스러움을 보증하지 않습니다.

부분 음원과 브라우저 음성은 위치 이동을 지원하지 않는다는 이유를 연계 플레이어에 표시합니다. 승인 음성 WAV/모델이 없으므로 실제 청취 인증은 별도입니다.

검증: Web 전체 84파일/338개, API245개 통과/1개 건너뜀, Worker 16개, lint/typecheck/build/Ruff·preflight55/55 통과. CI·Pages 최종 결과는 릴리스 결과에서 확인합니다.
