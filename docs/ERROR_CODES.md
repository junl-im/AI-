# ERROR CODES

| 코드 | 의미 | 사용자 조치 |
|---|---|---|
| SOA-1001 | 앱 루트 요소 없음 | 앱을 새로 설치하거나 관리자에게 문의 |
| SOA-2000 | 일반 API 오류 | 잠시 후 다시 시도 |
| SOA-2001 | API 연결 실패 | 네트워크와 API 실행 상태 확인 |
| SOA-2002 | API 응답 시간 초과 | 문장을 줄이거나 다시 시도 |
| SOA-3001 | Firebase 설정 없음 | 개발 환경 변수 설정 |
| SOA-4001 | 요청한 AI 엔진 없음 | 사용 가능한 엔진 선택 |
| SOA-5001 | 지원하지 않는 음성 형식 | MP3, WAV, FLAC, M4A 사용 |
| SOA-5002 | 음성 파일 크기 초과 | 25MB 이하 파일 사용 |

오류 코드와 한국어 메시지는 API와 웹에서 동일한 의미를 유지한다.
