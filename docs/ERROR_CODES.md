# ERROR CODES

| 코드 | 의미 | 사용자 조치 |
|---|---|---|
| SOA-2001 | 음성 시스템 자동 연결 실패 | 네트워크와 서버 상태를 확인하고 자동 재검사를 기다림 |
| SOA-2002 | 웹 요청 시간 초과 | 서버 상태 확인 후 재시도 |
| SOA-2003 | 사용자가 요청 취소 | 설정을 유지한 채 다시 생성 가능 |
| SOA-4001 | 실행 가능한 엔진 없음 또는 장애 격리 중 | 서버의 모델·Worker readiness 확인 |
| SOA-4002 | 엔진 실행 실패 | 품질 연구소의 진단과 서버 로그 확인 |
| SOA-4007 | 서버 작업 취소 | 필요할 때 다시 생성 |
| SOA-4008 | 서버 생성 제한 시간 초과 | 문장을 줄이거나 제한 시간 조정 |
| SOA-4009 | 같은 작업 ID에 다른 요청 payload 사용 | 새 UUID로 요청 |
| SOA-4011 | 작업이 아직 완료되지 않음 | 기존 job ID로 진행 상태를 계속 조회 |
| SOA-4012 | 완료 결과 TTL 만료 | 새 job ID로 해당 블록만 다시 생성 |
| SOA-4013 | 자동 엔진 후보가 모두 실패 | 엔진 readiness·cooldown 확인 후 재시도 |
| SOA-4104 | 임시 음원 없음 또는 만료 | 다시 생성 |

오류 메시지는 한국어로 제공하며 사용자 원문이나 로컬 파일 경로를 불필요하게 노출하지 않습니다.

## SOA-5000 · Voice Clone

- `SOA-5001`: 명시적 동의 항목 누락
- `SOA-5002`: 지원하지 않는 음성 파일
- `SOA-5003`: 음성 샘플 25MB 초과
- `SOA-5004`: 빈 음성 파일
- `SOA-5005`: 동의 기록 형식 오류
- `SOA-5006`: 품질 분석 형식 오류
- `SOA-5007`: 품질 차단 샘플
- `SOA-5008`: 손상된 WAV
- `SOA-5009`: 5초 미만 WAV
