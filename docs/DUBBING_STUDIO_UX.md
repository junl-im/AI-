# DUBBING STUDIO UX

현재 기준 버전: `0.8.7`

## 목적

SoriON의 만들기 화면은 채팅이 아니라 **장문 프로젝트를 문장별 음성 블록으로 편집하는 모바일
더빙 스튜디오**다. 참고 제품의 작업 순서는 학습하되 브랜드·구성·컴포넌트는 SoriON 고유
디자인으로 구현한다.

## 정보 구조

```text
프로젝트 상단바
├─ 홈 이동
├─ 프로젝트 제목
├─ 자동 저장 상태
├─ 음성 시스템 상태
├─ 현재 음원 다운로드
└─ 프로젝트·복제·품질·설정 메뉴

화자 및 읽기 설정
├─ 현재 목소리
├─ 목소리 미리듣기
├─ 목소리 선택 Sheet
└─ 속도·피치·감정·숫자 발음 Sheet

원고와 음성 블록
├─ 최대 20,000자 장문 원고
├─ 전체 원고 문장 분할·생성
├─ 문장별 직접 편집·생성·재생
├─ 분할·순서 이동·삭제
└─ 새 대사·쉼 추가

하단 고정 플레이어
├─ 현재 트랙
├─ 진행률과 시간
└─ 이전·재생/일시정지·다음
```

## 핵심 UX 규칙

- 첫 화면에는 작업 Dock을 표시하지 않는다.
- 제작 화면에서는 플레이어가 항상 같은 위치에 있어야 한다.
- 화자 선택은 기존 블록을 몰래 바꾸지 않고 이후 생성 기본값만 변경한다.
- 블록 텍스트를 수정하면 과거 음원과 진행 결과를 무효화한다.
- 파괴적 작업은 앱 내부 확인창을 거친다.
- 자동 저장은 프로젝트 제목·원고·읽기 설정·블록 순서·job ID를 함께 보존한다.
- 시스템·Mock·AI 음성을 동일한 품질로 표현하지 않는다.
- 고급 설정은 Sheet 안에 두고 원고·문장 편집을 가리지 않는다.

## 모바일 기준

- 주요 터치 영역은 최소 44px이다.
- 입력 글자 크기는 iOS 자동 확대를 피하도록 16px 이상으로 유지한다.
- 고정 플레이어와 Bottom Sheet는 `safe-area-inset-bottom`을 반영한다.
- 키보드가 열린 상태에서도 현재 편집 블록과 주요 생성 버튼이 가려지지 않아야 한다.
- 메뉴·Sheet·확인창은 Esc, 배경 클릭과 명시적 닫기 동작을 제공한다.

## 상태 연계

- Player Queue의 현재 트랙과 블록 재생 상태는 같은 데이터 원본을 사용한다.
- 프로젝트 복원은 서버 결과를 먼저 회수하고 만료된 블록만 재생성 대상으로 표시한다.
- workspace reset은 별도 상태를 부분 삭제하지 않고 공통 reset token을 사용한다.
- 연결이 늦어도 사용자가 요청한 장문 생성은 보존하고 엔진 준비 뒤 이어서 실행한다.
