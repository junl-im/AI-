# DUBBING STUDIO UX

현재 기준 버전: `0.9.3-beta.3 Engine Heartbeat 5.2`

## 목적

SoriON의 만들기 화면은 채팅이 아니라 **장문 프로젝트를 문장별 음성 블록으로 편집하는 모바일
더빙 스튜디오**다. 참고 제품의 작업 순서는 학습하되 브랜드·구성·컴포넌트는 SoriON 고유
디자인으로 구현한다.

## 정보 구조

```text
프로젝트 상단바
├─ 홈 이동
├─ 프로젝트 제목
├─ 자동 저장 상태
├─ 음성 시스템 상태
├─ 현재 음원 다운로드
└─ 프로젝트·복제·품질·설정 메뉴

화자 및 읽기 설정
├─ 현재 목소리
├─ 목소리 미리듣기
├─ 목소리 선택 Sheet
└─ 속도·피치·감정·숫자 발음 Sheet

내용과 음성 블록
├─ 최대 20,000자 장문 내용
├─ 전체 내용 문장 분할·생성
├─ 문장별 직접 편집·생성·재생
├─ 분할·순서 이동·삭제
└─ 새 대사·쉼 추가

하단 고정 플레이어
├─ 현재 트랙
├─ 진행률과 시간
└─ 이전·재생/일시정지·다음
```

## 핵심 UX 규칙

- 첫 화면에는 작업 Dock을 표시하지 않는다.
- 제작 화면에서는 플레이어가 항상 같은 위치에 있어야 한다.
- 화자 선택은 기존 블록을 몰래 바꾸지 않고 이후 생성 기본값만 변경한다.
- 블록 텍스트를 수정하면 과거 음원과 진행 결과를 무효화한다.
- 파괴적 작업은 앱 내부 확인창을 거친다.
- 자동 저장은 프로젝트 제목·내용·읽기 설정·블록 순서·job ID를 함께 보존한다.
- 시스템·Mock·AI 음성을 동일한 품질로 표현하지 않는다.
- 고급 설정은 Sheet 안에 두고 내용·문장 편집을 가리지 않는다.

## 모바일 기준

- 주요 터치 영역은 최소 44px이다.
- 입력 글자 크기는 iOS 자동 확대를 피하도록 16px 이상으로 유지한다.
- 고정 플레이어와 Bottom Sheet는 `safe-area-inset-bottom`을 반영한다.
- 키보드가 열린 상태에서도 현재 편집 블록과 주요 생성 버튼이 가려지지 않아야 한다.
- 메뉴·Sheet·확인창은 Esc, 배경 클릭과 명시적 닫기 동작을 제공한다.

## 상태 연계

- Player Queue의 현재 트랙과 블록 재생 상태는 같은 데이터 원본을 사용한다.
- 프리셋·설정·블록·대기열의 재생 버튼은 별도 적용 단계를 요구하지 않고 선택값 적용과 재생을 한 동작으로 처리한다.
- 직접 누른 한 블록·프리셋 미리듣기만 자동 재생하고 전체 장문 일괄 생성은 블록마다 재생하지 않는다.
- 프로젝트 복원은 서버 결과를 먼저 회수하고 만료된 블록만 재생성 대상으로 표시한다.
- workspace reset은 별도 상태를 부분 삭제하지 않고 공통 reset token을 사용한다.
- 연결이 늦어도 사용자가 요청한 장문 생성은 보존하고 엔진 준비 뒤 이어서 실행한다.

## PC 3단 편집 구조

- 1180px 이상: 왼쪽 프로젝트 히스토리 / 중앙 Chat Workspace·내용 편집·Timeline / 오른쪽 Voice Drawer.
- 1180px 미만: 기존 모바일 단일 열과 Sheet 기반 음성 선택을 유지합니다.
- Timeline은 가로 클립, 시간 눈금, 플레이헤드, 가위·삭제 직접 도구를 우선 표시합니다.
- API·Worker·GPU 실패는 상단 점 상태와 중앙 시스템 메시지에 동시에 표시합니다.

## PC·모바일 공통 음성 설정 계약

- 속도는 0.7~1.4, 높낮이는 -6~6 정수 단위로 제공하고 모든 화면이 같은 옵션 원본을 사용합니다.
- 말투는 기본, 밝게, 차분하게, 광고처럼, 슬프게, 힘있게 6종을 같은 값으로 저장합니다.
- 과거 저장값과 외부 입력은 UI 표시와 API 요청 전에 clamp·정규화합니다.
- 목소리·읽기 설정 Sheet는 dialog 초점 순환, Escape, 배경 스크롤 잠금과 실행 버튼 초점 복귀를 지킵니다.
- 미리듣기 중에는 같은 요청을 다시 시작하지 않으며 진행 상태를 버튼 문구와 접근성 상태로 알립니다.
