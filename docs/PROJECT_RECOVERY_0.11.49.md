# 0.11.49 프로젝트 저장 복구

생성 완료 프로젝트를 IndexedDB에 기록하지 못한 경우, 같은 ID와 원본 대본·성우·타임라인 구성·작업 ID를 브라우저 `localStorage`에 임시 보관합니다. 페이지를 새로고침해도 복구 버튼이 남으며, 저장 성공 또는 새 작업 시작 시 임시 사본을 지웁니다. IndexedDB 저장이 실제로 완료됐는지 다시 조회해 거짓 실패 안내도 제거합니다.

임시 사본은 최대 128,000자, 대본 20,000자, 타임라인 240개, 보관 기간 30일로 제한합니다. 저장소 차단·용량 부족이면 현재 탭의 메모리에서만 재시도하며 화면에 탭을 닫기 전 저장하라고 알립니다. 다른 기기·브라우저로 동기화하지 않습니다. 오디오 바이트·WAV·모델·권리 자료를 자동 저장하거나 업로드하지 않습니다.

검증은 재시도 동일 ID, 리마운트 복원, 이미 저장된 항목 확인, 손상·만료·초과 사본 무시를 포함합니다. 승인된 실제 5성우 WAV와 모델이 없으므로 사람 청취 평가와 음질 인증은 진행하지 않았습니다.
