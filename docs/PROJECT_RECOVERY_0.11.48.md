# 0.11.48 프로젝트 저장 복구

음성 블록 생성 후 최근 프로젝트 목록에 기록하는 단계가 실패해도 동일 프로젝트 ID, 원본 대본, 블록별 목소리와 작업 ID를 현재 탭 메모리에 유지합니다. 사용자가 `프로젝트 저장 다시 시도`를 누르면 동일 기록을 IndexedDB에 put하므로 중복 항목을 생성하지 않습니다. 성공하면 안내를 닫고 실패하면 다시 시도할 수 있습니다. 새 음성 제작 또는 작업 비우기는 이전 실패 상태를 정리합니다.

0.11.47 작업공간 자동 저장과 이 프로젝트 목록 저장은 별개입니다. 새로고침을 넘는 전용 복구는 아직 구현되지 않았습니다. 서버 음원은 만료될 수 있으나 원본 대본과 현재 편집 세션을 우선 보존합니다.

기본 성우 5명의 숫자·영문 혼합 장문에서 분할 최대 길이, 소수점 보존, 쉼과 속도 범위의 코드 회귀 검사를 추가했습니다. 실제 WAV·모델이 없으므로 성우 음색이나 청취 자연스러움을 인증하지 않습니다.

검증: Web 전체 85파일/340개, API246개 통과/1개 건너뜀, Worker16개, lint/typecheck/build/Ruff·preflight55/55 통과. CI·Pages 배포는 최종 확인합니다.
