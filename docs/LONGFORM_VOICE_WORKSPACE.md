# LONGFORM VOICE WORKSPACE

현재 기준 버전: `0.9.2`

## 제품 결정

음성 제작의 기본 입력은 채팅이 아니라 **장문 원고 편집기**다. 주요 사용자는 광고 대본,
오디오북, 강의, 내레이션과 영상 더빙처럼 여러 문장을 한 번에 제작한다. 채팅형 한 문장 전송은
핵심 목표와 맞지 않으므로 기본 제작 화면으로 복귀시키지 않는다.

## 작업 흐름

```text
긴 원고 붙여넣기 또는 작성
→ 읽기 옵션과 목소리 선택
→ 문장·긴 구간 자동 분할
→ 앞 블록부터 순차 생성
→ 완성 즉시 Dock 재생
→ 타임라인에서 순서·쉼·문장 수정
```

## 원고 편집기 계약

- 최대 20,000자
- 일반 Enter는 줄바꿈
- Ctrl/⌘+Enter는 제작 시작
- 생성 후 원고를 비우지 않음
- 문자 수, 문단 수, 음성 블록 수, 예상 길이 표시
- 숫자 발음 보정, 광고 톤, 밝은 톤, 느린 읽기 옵션
- 브라우저 지원 시 한국어 받아쓰기

## 생성 계약

- Web 요청은 항상 `engine_id=auto`
- 새 제작은 기존 타임라인과 Player queue를 명시적으로 초기화
- 문장 사이 기본 0.5초 쉼 블록
- 첫 ready 블록부터 Dock에 연결
- 실패 블록만 재시도
- 서버 미연결 시 타임라인을 먼저 만들고 연결 복구 뒤 같은 요청을 자동 재개
- POST를 네트워크 오류만으로 무조건 재전송하지 않으며 job ID 결과를 우선 복구

## 세션·프로젝트

- 전송 전 원고와 읽기 옵션도 작업공간 세션에 저장
- 프로젝트는 원문과 문장 순서에 맞춘 job ID 배열을 보존
- 불러오기는 새 합성보다 저장 job 결과를 먼저 조회
- 블록 revision이 달라지면 과거 생성 결과를 폐기

## IA 원칙

- 첫 화면: 제품 설명과 시작 동선만 제공하고 Dock 숨김
- 만들기: 장문 원고가 중심, 목소리 선택은 보조 열, 타임라인은 후속 편집
- 복제·품질·프로젝트·설정: 같은 상단 브랜드와 Dock 내비게이션 사용
- 모든 상단 브랜드 클릭은 첫 페이지로 이동
