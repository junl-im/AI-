# Studio Playback & Timeline UX

SoriON AI 0.10.5는 PC 편집 화면에서 재생과 텍스트 수정이 서로 화면을 밀어내지 않도록, Dock과 클립 편집의 주 역할을 다시 분리한다.

## PC Dock

Dock의 핵심 순서는 `재생/일시정지 → 진행바 → 시간/제목 → 보조 동작`으로 고정한다. 재생 버튼은 항상 맨 앞에 있고 진행바는 바로 옆에서 남은 가로 폭을 우선 사용한다.

- PC 일반 Dock은 한 줄의 얕은 transport를 기본으로 한다.
- 만들기 화면 전용 Dock도 같은 순서를 사용하며 PC에서는 한 줄을 유지한다.
- 이전/다음, 반복, 속도, 대기열, 다운로드 같은 기능은 진행바보다 우선하지 않는 보조 제어로 취급한다.
- 장식용 파형 때문에 Dock 높이를 늘리지 않는다.
- 모바일에서는 제목과 일부 보조 제어를 줄여 재생 버튼과 진행 위치를 먼저 보존한다.

## 선택 클립 빠른 편집

타임라인 카드는 위치·상태·대사 미리보기와 선택의 역할에 집중한다. 실제 텍스트 수정은 선택 클립 전용 `빠른 편집` 패널에서 수행한다.

- 클립을 선택하면 현재 화자·클립 정보와 대사가 빠른 편집기에 표시된다.
- 카드의 편집 버튼이나 Enter 키는 해당 클립을 선택하고 빠른 편집기에 포커스를 이동한다.
- 빠른 편집기에서 저장, 미리듣기/재생, 재생성, 분할, 삭제를 한곳에서 수행한다.
- `Ctrl+Enter` 또는 `Cmd+Enter`는 현재 대사를 저장한 뒤 재생성을 요청한다.
- 카드 내부에는 작은 textarea를 반복 배치하지 않아 긴 타임라인의 세로 밀도와 오입력을 줄인다.

## 프리셋 버튼 상태

프리셋 미리듣기 버튼은 상황에 따라 다음 상태를 표시한다.

- idle: 재생
- loading: 준비 취소
- playing: 일시정지
- paused: 계속 재생

다른 프리셋을 선택하면 이전 대기 요청과 늦게 도착한 결과를 폐기한다.

## 타임라인 직접 조작

- 타임라인의 준비된 음성 클립 위치를 클릭해 재생 위치를 이동한다.
- Space로 선택 클립을 재생하거나 일시정지한다.
- Enter로 선택 클립 빠른 편집기에 진입한다.
- Delete 또는 Backspace로 선택 클립을 삭제한다.
- Alt+왼쪽/오른쪽으로 클립 순서를 바꾼다.
- 확대·축소와 현재 재생 위치 라벨을 제공한다.
- 재생 중인 클립을 자동 선택하고 화면 중앙으로 가져온다.

## 준호·민준 프리셋

기기에 같은 성별 한국어 음성이 하나뿐이어도 준호와 민준은 해당 음성을 프리셋별 속도·높낮이 설정과 함께 순환 사용한다. 반대 성별 음성은 계속 차단한다. Browser Speech, Windows, macOS, MeloTTS가 같은 정책을 사용한다.
