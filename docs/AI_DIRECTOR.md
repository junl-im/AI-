# AI DIRECTOR

현재 기준 버전: `0.9.2`

## 목적

사용자가 엔진과 세부 파라미터를 공부하지 않아도 제작 목적에 맞는 한국어 음성 계획을 자동으로 만든다.

## API

```http
POST /api/v1/director/plan
Content-Type: application/json
```

```json
{
  "text": "제1장. AI 기술은 빠르게 발전하고 있습니다.",
  "use_case": "auto",
  "voice_id": "sori-warm",
  "preserve_wording": true
}
```

응답에는 다음 정보가 포함된다.

- 감지된 제작 용도
- 정규화된 내용과 생성 구간
- 발음 힌트
- 문장별 권장 쉼 길이
- 권장 속도·피치·감정
- 엔진 자동 순서
- 필요한 기능과 선택적 후처리
- 장문·감정 지원 관련 경고

## 원칙

- 원문 보존이 기본이다.
- 외부 유료 API를 호출하지 않는다.
- 로컬 LLM이 없어도 규칙 기반 계획을 항상 생성한다.
- 엔진 선택은 UI 옵션이 아니라 서버 정책이다.
- 음색 복제·변환은 소유권과 명시적 동의가 있을 때만 수행한다.
