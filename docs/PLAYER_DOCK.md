# LINKED PLAYER DOCK

## 목적

SoriON의 모든 음원은 화면마다 별도 플레이어를 만들지 않고 하단 Dock의 단일 `audio` 요소에 연결한다. TTS 생성 결과와 복제 원본 샘플이 같은 재생 규칙을 사용한다.

## 0.6.0 기능

- 최대 20개의 재생 대기열
- 현재 음성 자동 선택
- 이전·다음 음성
- 파형 영역 클릭 탐색
- 현재 시간과 전체 시간
- 반복 끔, 전체 반복, 한 곡 반복
- 0.75배부터 2배까지 재생 속도
- 현재 음원 다운로드
- 대기열 개별 삭제와 전체 비우기
- 새 TTS 결과와 복제 샘플 자동 연결

## 소유권과 메모리

브라우저에서 생성한 Object URL은 `revokeOnRemove`가 설정된 트랙만 Dock store가 관리한다. 트랙 삭제, 대기열 비우기, 20개 초과 제거 시 `URL.revokeObjectURL`을 호출한다. API의 일반 HTTP URL은 해제하지 않는다.

## 재생 대기열 규칙

- 새 음원은 대기열 마지막에 추가하고 현재 음원으로 선택한다.
- 반복 끔 상태에서 마지막 음원이 끝나면 정지한다.
- 전체 반복은 마지막에서 첫 음원으로 이동한다.
- 한 곡 반복은 같은 음원을 처음부터 다시 재생한다.
- 재생 중 이전·다음 이동 시 새 음원이 준비되면 재생을 이어간다.

## 반응형

모바일은 메뉴와 플레이어가 세로로 쌓인다. PC는 2프레임 비율에 맞춰 메뉴와 플레이어를 한 줄에 배치하며 재생 대기열은 Dock 위에 독립 패널로 열린다.
