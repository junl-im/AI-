# SoriON AI 0.9.3-beta.3 Engine Heartbeat 4 Patch

Base: `0.9.3-beta.3 Engine Heartbeat 3`

This patch makes all four landing steps visible without horizontal clipping and introduces a responsive three-pane PC studio: project history on the left, Chat Workspace and CapCut-style timeline in the center, and a compact Voice Drawer on the right. API, Worker, and GPU status remain visible in the top header and failures are copied into workspace system messages.

Apply by overwriting the Engine Heartbeat 3 folder, run `APPLY_PATCH.cmd`, review in GitHub Desktop, commit and push. No tracked file is deleted relative to Engine Heartbeat 3.
