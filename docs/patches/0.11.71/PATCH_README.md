# SoriON AI 0.11.71 덮어쓰기 패치

기준 버전: **0.11.70** (`8facc3a34436`). 기존 작업 변경을 먼저 보관하고 저장소 루트에 패치 ZIP을 압축 해제해 덮어쓰세요. `.git`은 포함하지 않습니다. 변경·신규 파일 목록은 `PATCH_MANIFEST.txt`를 참조하세요. 삭제 파일은 없습니다.

기본 성우의 브라우저 화면 공유가 무음인 Windows PC를 위해 시스템 출력 루프백 보조 앱을 추가했습니다. 사이트 저장 화면에서 약 50MB 보조 앱 ZIP을 받고 압축 해제한 뒤 `SoriONAudioBridge.exe`를 실행하세요. 보조 앱이 새로 연 페이지에서 기본 성우 대사를 만든 후 `Windows 보조 앱으로 원래 음색 MP3 저장`을 누르면 클립을 다시 재생해 녹음하고 WAV·MP3를 제공합니다. 창을 닫으면 연결이 끊기며 다른 앱의 소리도 녹음될 수 있습니다. 오류 아래의 다른 음색 로컬 MP3 경로도 남아 있고 첫 모델 다운로드 약 380MB가 필요합니다.

Chrome 로컬 개발 페이지에서 `sori-warm`이 Heami로 선택된 뒤 실제 MP3 파일 다운로드와 재디코딩된 음성을 확인했습니다. 브라우저가 물으면 소리온의 ‘이 기기의 앱 접근’을 허용하세요. 배포된 Pages 버튼 직접 클릭과 다른 PC·Edge 실기기 검증은 남아 있습니다. 자세한 결과와 한계는 `docs/DEFAULT_VOICE_EXPORT_DIAG_0.11.71.md`를 참조하세요.
