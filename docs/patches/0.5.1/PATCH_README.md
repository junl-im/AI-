# 0.5.0 → 0.5.1 패치

## 적용 조건

현재 저장소 루트의 `package.json` 버전이 `0.5.0`일 때 사용합니다.

## 적용 방법

1. GitHub Desktop에서 작업 중인 변경사항을 커밋하거나 백업합니다.
2. `.git` 폴더는 유지합니다.
3. 이 패치 ZIP의 파일과 폴더를 저장소 루트에 압축 해제합니다.
4. 같은 이름의 파일은 모두 덮어씁니다.
5. 이번 패치에서 삭제할 기존 파일은 없습니다.
6. `npm run quality:rules`와 가능한 웹·API 검사를 실행합니다.
7. 공개 사이트에서 `BUILD v0.5.1`을 확인합니다.

## 핵심 변경

- 모바일·PC 상단을 압축형 배너로 변경
- 브랜드명과 한국어 핵심 문장의 순환 페이드
- `SoriON AI`의 `I`를 CSS 마이크로 표현
- PC Voice Core에 CSS 스튜디오 마이크 추가
- 모션 감소 환경의 정적 표시
