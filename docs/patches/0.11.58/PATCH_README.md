# SoriON AI 0.11.58 패치

기준: 0.11.57 R1 (`509032d`) · 대상: 0.11.58.

기기 내 모델에서 만든 WAV는 IndexedDB에 보관되며 동일 작업공간 복원 시 클립·Dock·다운로드에 다시 연결됩니다. 저장 공간이 부족하면 즉시 파일 다운로드를 안내합니다. `작업·WAV 백업 만들기`로 대본과 로컬 모델 WAV를 JSON 파일에 묶고, 다른 PC의 `작업 백업 가져오기`로 불러올 수 있습니다. 가져오기는 현재 작업공간을 바꾸므로 확인 창을 표시합니다.

기본 성우 화면 공유 녹음의 WAV·MP3는 이 백업에 포함되지 않으므로 따로 다운로드하세요. 화면 공유 오디오가 무음인 PC에서 기본 성우 원본 음색을 저장하는 기능은 아직 제공되지 않습니다. 백업 크기 제한은 160MB이며 자동 클라우드 동기화는 없습니다.

패치 ZIP을 기존 저장소 루트에 덮어쓰고 `npm run quality:preflight`, `npm run test:ci`, `npm run build`로 검증하세요. 삭제 파일은 없습니다.
