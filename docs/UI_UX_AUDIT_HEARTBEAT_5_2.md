# UI/UX AUDIT · Engine Heartbeat 5.2

기준본: `0.9.3-beta.3 · Engine Heartbeat 5.1 · Web Quality Hotfix`
검토일: `2026-08-02`

## 점검 결과

### 수정 완료 · 높음

1. **PC와 모바일 음성 설정 불일치**
   - PC는 `sad`, 모바일은 `calm`을 사용해 화면 전환 시 선택 표시가 사라질 수 있었습니다.
   - 속도 범위도 PC `0.75~1.25`, 모바일 `0.7~1.4`로 달랐습니다.
   - 말투 6종과 속도·높낮이 범위를 단일 설정 모듈에서 공유하도록 통합했습니다.

2. **높낮이 소수 단위와 API 정수 계약 충돌**
   - PC 슬라이더는 0.5 단위를 허용했지만 FastAPI의 pitch 계약은 정수입니다.
   - 0.5 단위 요청이 422 응답으로 이어질 수 있어 1단위로 통일하고 이전 저장값을 반올림·범위 제한합니다.

3. **Bottom Sheet와 확인창의 초점 관리 누락**
   - 열릴 때 초점 이동, Tab 순환, Escape 닫기, 닫힌 뒤 실행 버튼으로 복귀, 배경 스크롤 잠금이 없었습니다.
   - 공통 `useModalDialog` 훅으로 위 동작을 일관되게 적용했습니다.

### 수정 완료 · 중간

4. **미리듣기 중 중복 요청 가능**
   - 모바일 목소리 목록과 설정 Sheet에서 재생 준비 중에도 버튼을 다시 누를 수 있었습니다.
   - 모든 관련 재생 버튼을 비활성화하고 `aria-busy`와 진행 문구를 표시합니다.

5. **동작하지 않는 탭처럼 보이는 목소리 분류**
   - `전체 / 한국어 / 장문 추천`이 클릭 가능한 탭처럼 보였지만 실제 필터 기능은 없었습니다.
   - 비조작형 정보 태그로 바꿔 잘못된 기대를 제거했습니다.

6. **프로젝트 메뉴와 현재 프로젝트의 키보드 의미**
   - 프로젝트 메뉴는 바깥 클릭과 Escape로 닫히지 않았고, 현재 프로젝트 표시는 동작 없는 버튼이었습니다.
   - 메뉴 닫기·초점 복귀를 추가하고 현재 프로젝트는 비조작형 현재 상태 요소로 변경했습니다.

### 수정 완료 · 낮음

7. **데스크톱 보조 텍스트 가독성**
   - 프로젝트 레일, Voice Drawer, 작업 메시지, 타임라인 눈금에 7~9px 텍스트가 다수 있었습니다.
   - 핵심 보조 텍스트를 10~12px로 높이고 대비와 터치·클릭 영역을 보강했습니다.

8. **접힌 패널의 리사이저 상태 혼동**
   - 패널이 접혀도 리사이저가 기존 너비를 읽어 주고 조작 가능했습니다.
   - 접힌 동안 리사이저를 비활성화하고 `접힘` 상태와 제어 대상 패널을 명시합니다.

## 추가된 회귀 계약

- PC·모바일 공통 속도·높낮이 범위와 말투 6종
- 과거 저장값의 속도·높낮이 보정
- Sheet 초기 초점, Escape 닫기, 초점 복귀, 배경 스크롤 잠금
- 목소리 라디오 방향키 이동
- 미리듣기 중 중복 요청 차단
- 프로젝트 메뉴 Escape 닫기와 확인창 안전 동작 초점
- dependency-free preflight의 공통 설정·modal 계약 검사

## 남은 수동 검증

아래 항목은 실제 브라우저와 설치된 Web 의존성이 필요합니다.

- 360px, 390px, 430px에서 Sheet 높이·safe area·가상 키보드 겹침
- 1024px, 1280px, 1440px에서 3단 레이아웃과 6개 말투 버튼 줄바꿈
- NVDA, VoiceOver에서 dialog·radiogroup·separator 읽기 순서
- Chrome, Safari에서 range 키보드 조작과 초점 링
- 실제 TTS 연결 상태에서 연속 미리듣기 차단과 재활성화

## 판정

이번 패치는 새로운 제작 기능보다 **설정 일관성, 오류 예방, 키보드 접근성, 가독성**을 우선한 안정화 패치입니다. 제품 런타임의 TTS 생성·저장·타임라인 계약은 유지합니다.
